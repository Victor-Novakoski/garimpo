# 017. Modo API usa o SDK oficial da Anthropic, e o Go sobe para 1.25

- **Data:** 2026-11-10
- **Status:** ativa

## Contexto

O SDK cuida de retry, erros tipados e saída estruturada, e é o caminho recomendado. Custa a subida de versão do Go e as dependências dele; a coleta segue só com a biblioteca padrão.

## Decisão

Modo API usa o SDK oficial da Anthropic, e o Go sobe para 1.25.
