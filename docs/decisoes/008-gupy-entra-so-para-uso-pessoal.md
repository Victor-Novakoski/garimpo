# 008. Gupy entra só para uso pessoal

- **Data:** 2026-11-10
- **Status:** ativa

## Contexto

É onde está a maior parte das vagas BR, mas os termos proíbem agregar o conteúdo. Assim o risco fica baixo e o projeto público segue limpo.

## Decisão

Gupy entra só para uso pessoal: coletor desligado por padrão, só link para a vaga original, nunca no demo público.

## Consequência

Migrada do antigo `docs/DECISIONS.md`, que guardava a decisão e o porquê; o efeito está descrito acima.
