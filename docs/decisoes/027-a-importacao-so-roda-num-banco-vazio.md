# 027. A importação só roda num banco vazio e não mexe no arquivo

- **Data:** 2026-11-11
- **Status:** ativa

## Contexto

Juntar dois registros com números próprios daria o mesmo `#12` a duas vagas. Num banco vazio os números entram iguais, e o arquivo fica de cópia.

## Decisão

A importação só roda num banco vazio e não mexe no arquivo.
