# 022. A vaga só sai da lista quando a pessoa marca

- **Data:** 2026-11-11
- **Status:** ativa

## Contexto

O Victor nem sempre lê a lista inteira. Esconder o que já apareceu faria ele perder vaga boa sem saber.

## Decisão

A vaga só sai da lista quando a pessoa marca; aparecer numa rodada não conta como vista.
