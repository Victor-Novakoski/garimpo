# 024. Mais fontes antes do banco

- **Data:** 2026-11-11
- **Status:** ativa

## Contexto

Com 3 empresas a lista dependia quase só da Stone. Mais vagas boas valem mais agora do que guardar poucas num banco.

## Decisão

Mais fontes antes do banco: Lever e 13 empresas novas no Greenhouse, cada uma conferida pela API.
