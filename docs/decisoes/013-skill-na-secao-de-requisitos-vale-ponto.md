# 013. Skill na seção de requisitos vale ponto cheio

- **Data:** 2026-11-10
- **Status:** ativa

## Contexto

Na segunda nota real, a Jazida pedia React nos requisitos e levava só metade, a Coodesh ganhava React por um `utm_medium=react-brasil-vagas` e vagas de vendas e ciência de dados com 0 de tecnologia ainda apareciam.

## Decisão

Skill na seção de requisitos vale ponto cheio; links não contam; vaga sem nenhuma skill do perfil sai no filtro.
