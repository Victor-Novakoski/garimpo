# Decisões

Registro das escolhas e do porquê. A mais nova em cima.

| Data | Decisão | Por quê |
| --- | --- | --- |
| 11/11/2026 | A API entra com um token fixo do dono (`GARIMPO_API_TOKEN`); o Supabase Auth fica para a etapa 4 | Ainda não existe painel para fazer login e o Victor roda tudo local. O token funciona hoje sem depender de nada, e a checagem fica atrás de uma interface (`api.Authenticator`) para o login entrar sem mexer nas rotas |
| 11/11/2026 | Roteador da API é o `net/http` da biblioteca padrão, e não o `chi` | Desde o Go 1.22 o roteador padrão entende método e parâmetro no caminho (`GET /jobs/{number}`). Para quatro rotas, uma dependência a menos |
| 11/11/2026 | Driver do Postgres é o `pgx`, sem preparar comandos | É o driver mais usado em Go e fala o protocolo nativo. O pooler do Supabase divide as conexões entre clientes, e comando preparado não sobrevive de uma consulta para a outra |
| 11/11/2026 | As regras do fluxo ficam num lugar só (`tracker/rules.go`); arquivo e banco carregam as entradas, aplicam a mesma função e gravam o que mudou | Duas implementações das mesmas regras, uma em Go e outra em SQL, iam divergir com o tempo. Uma busca de emprego tem algumas centenas de vagas: carregar tudo numa rodada custa pouco |
| 11/11/2026 | Tabelas com RLS ligado e nenhuma policy | O Supabase publica uma API REST para tudo que está no schema `public`. Sem RLS, a chave pública do projeto leria as anotações. O Garimpo entra como dono das tabelas, que não passa pelo RLS |
| 11/11/2026 | A URL do banco vem só de variável de ambiente; o `-state` escolhe entre arquivo e banco, mas nunca recebe a URL | A URL leva a senha. Em flag, ela ficaria no histórico do terminal e na lista de processos |
| 11/11/2026 | A importação só roda num banco vazio e não mexe no arquivo | Juntar dois registros com números próprios daria o mesmo `#12` a duas vagas. Num banco vazio os números entram iguais, e o arquivo fica de cópia |
| 11/11/2026 | O registro passa a guardar os motivos da nota da última rodada | A tela da vaga precisa mostrar por que a nota é aquela sem coletar de novo. Continua valendo que a nota não é a verdade: ela é recalculada a cada rodada |
| 11/11/2026 | Testes do banco rodam num Postgres de verdade, só quando `GARIMPO_TEST_DATABASE_URL` existe; a CI sobe um | Simular o banco testaria a simulação. | 11/11/2026 | Mais fontes antes do banco: Lever e 13 empresas novas no Greenhouse, cada uma conferida pela API | Com 3 empresas a lista dependia quase só da Stone. Mais vagas boas valem mais agora do que guardar poucas num banco |

| 11/11/2026 | A vaga só sai da lista quando a pessoa marca; aparecer numa rodada não conta como vista | O Victor nem sempre lê a lista inteira. Esconder o que já apareceu faria ele perder vaga boa sem saber |

| 10/11/2026 | Modo API usa o SDK oficial da Anthropic, e o Go sobe para 1.25 | O SDK cuida de retry, erros tipados e saída estruturada, e é o caminho recomendado. Custa a subida de versão do Go e as dependências dele; a coleta segue só com a biblioteca padrão |
